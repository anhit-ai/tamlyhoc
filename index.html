Hướng dẫn Triển khai lên Vercel

Trang web được thiết kế theo cấu trúc tĩnh (Static Site), hoàn toàn tương thích và tối ưu 100% với nền tảng Vercel miễn phí.

Cách 1: Cập nhật qua GitHub (Khuyên dùng)
  1. Truy cập kho GitHub anhit-ai/tamlyhoc.
  2. Chọn Add file -> Upload files.
  3. Kéo thả các file index.html, tlhdc_index.html, hdtkcc_index.html, tlhnc_index.html, tlhpt_index.html, vercel.json.
  4. Nhấn Commit changes. Vercel sẽ tự động build lại trang web sau 20 giây!
Cách 2: Kéo thả trực tiếp lên Vercel Dashboard

Bấm nút Add New... -> Project trên Vercel rồi kéo thả toàn bộ thư mục Tamlyhoc vào khung tải lên.

Đặt lại Toàn bộ Dữ liệu?
